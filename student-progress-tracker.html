Monthly Attendance

Day-wise attendance for every student across the whole month. Sundays are marked as holidays automatically.

Import Monthly Sheet (Grid Format)

Already have a whole month's attendance in a grid — one row per student, one column per day? Upload it here and it will display directly in the grid below, for the month currently selected.

📋 Required format

One row per student. First two columns are Student Name and Roll Number, followed by one column per day of the month (headed 1, 2, 3 … up to the last day). Each cell holds that day's status: P (Present), A (Absent), L (Leave), or T (Late) — leave a cell blank for no record. Sunday columns can be left blank or marked H; they're always shown as holidays regardless. The file is applied to whichever month is selected below.
